# rasterizer-from-scratch

YouTube チャンネル「車輪の再発明ラボ」で、C++ を使ってソフトウェアラスタライザーを一から作っている動画シリーズのコードです。
GPU を使わずに、点を打つところから始めて、影や透明、本物っぽい素材のある 3D の世界を描けるところまで進みます。

## 必要なもの
- Visual Studio Community（「C++によるデスクトップ開発」を入れたもの）

これだけで動きます。ほかのツールやライブラリは使いません。

## 動かし方
1. このページの緑色の「Code」ボタンを押し、「Download ZIP」を選びます。
2. ダウンロードした ZIP を右クリックし、「すべて展開」を選びます。
3. 見たい回のフォルダを開き、`.sln` ファイルをダブルクリックします。
4. Visual Studio が開いたら、F5 キーを押します。

## フォルダの見方
各回のフォルダは、2つずつあります。

- `epXX_start` … その回を始める時点のコードです。動画を見ながら、ここから一緒に書き進められます
- `epXX_done` … その回を終えた時点のコードです。うまく動かないときは、こちらと見比べてください

前の回で詰まってしまっても、次の回の `_start` から合流できます。

## 番外編の実験用プログラム
`extra/` フォルダには、番外編の動画で使った実験用プログラムが入っています。それぞれのフォルダが1つの Visual Studio プロジェクトです。`.sln` ファイルをダブルクリックして、F5 キーを押すと動きます。

`extra/fill_rule`（番外編「塗りのルール」）は、ラスタライザー編 #04 の三角形の塗り方に、辺の上ぴったりのピクセルをどの三角形が塗るか（塗りのルール）の切り替えと、拡大表示を足したものです。1〜5 キーで絵を選び、T キー（左上ルール）・B キー（右下ルール）・G キー（「> 0」だけを塗る）・E キー（「>= 0」を塗る）でルールを切り替えます。V キーで、ひとつだけ表示・左右に並べる・違いを赤で表示、を切り替えます。Z キー・X キーで拡大・縮小、矢印キーで表示する場所を動かします。C キーでピクセルの境目と中心の印を、W キーで三角形のふちの線を、A キーで塗った回数（二重に塗られたピクセルが明るくなります）を表示します。Esc キーで終わります。
